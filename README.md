A one-line entry for the make.fun bounty [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b): one funny line a hopeless tech-support agent says to a desperate customer, at most 199 characters.

The line:

> Have you tried turning it off and on again? Perfect — that's step one. Step two is the same thing, and honestly, so is my entire career.

## Run it

```
node main.ts
```

This writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` when that variable is set, and in this directory otherwise, then reads the file back and checks the bytes match. Running it twice produces byte-identical output.
